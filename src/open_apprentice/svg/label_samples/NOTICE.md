# Label-placement fixtures

`pipeline.svg`, `crowded-services.svg` and `mixed-layout.svg` (boxes with attached text labels, for the label-placement lane) were generated by a script written for this project, in the style of exported diagrams. They are authored fixtures, NOT third-party or user-exported files. `data-for` and `data-role` attributes mark each label's box and role.

`tight-grid.svg` and `edge-cluster.svg` are two more such fixtures (tight spacing, so the right-hand spot is often blocked or leaves the canvas).

They live apart from `../samples/` because the experimental badge lane lists every file there as a selectable sample.
