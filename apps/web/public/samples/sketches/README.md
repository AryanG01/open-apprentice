Synthetic wobbly wireframes, 1280 x 720, made by this repo's own renderer (`draw_wireframe` in
`src/open_apprentice/evaluation/campaign_sketch_eval.py`, seeded, deterministic) from three development banners
(`short_a`, `teach_before`, `de_long_a`). They are not hand drawn: scribble rows stand for text, a crossed box for the
product picture. Used by the "Use a sample sketch" button.
